# Hardware support

| Feature | Support |
|---|---|
| OS / CPU / RAM detection | Yes |
| CUDA availability via PyTorch | Yes |
| NVIDIA name/memory via NVML or torch | Yes |
| NVML power/energy | When available |
| Intel RAPL | Linux powercap |
| AMD GPU energy | Not yet |
| Apple Silicon energy counters | Not yet |
| Android direct profiling | Planned |

Unsupported capabilities degrade gracefully.
